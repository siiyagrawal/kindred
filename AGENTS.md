## Project architecture

- Keep Harmony's prototype data client-side until persistence is explicitly requested, so the polished discovery flow remains deployable without backend setup.
- Derive Harmony's network geometry from its stage ResizeObserver, not viewport dimensions, so embedded and resized layouts remain accurate.
